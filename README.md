## Getting Started

```bash
git clone https://github.com/Bannysukumar/portfolio-website.git
cd portfolio-website
npm install
npm run dev
```

Scripts defined in package.json:

- `npm run dev` — `vite --host`
- `npm run build` — `tsc -b && vite build`
- `npm run lint` — `eslint .`
